# Decision Lenses

Use this skill for a medium- or high-impact decision. The user should only need to ask for a decision review.

By default, read and apply all four core jobs:

- [SEO reviewer](references/roles/seo-reviewer.md)
- [Marketing reviewer](references/roles/marketing-reviewer.md)
- [Engineering reviewer](references/roles/engineering-reviewer.md)
- [Infrastructure reviewer](references/roles/infrastructure-reviewer.md)

Leave a job out only when it plainly cannot affect the decision. Add another perspective when the decision clearly involves a domain such as legal, finance, security, product, accessibility, or operations; the user does not need to route the review.

For each perspective, consider likely benefits and risks, evidence versus assumptions, important unknowns, and what could change the recommendation. Then give one compact synthesis: where the perspectives agree, the main tradeoff or counterpoint, your recommendation, confidence, and the smallest sensible next step.

Do not invent external facts; identify what needs to be checked. Protect secrets, preserve existing changes, and treat the recommendation as advice rather than authorization for system changes.
